### 2. 신청 전 권고: 실제 비공개 연락 경로

Contact는 GitHub 계정이 필요한 공개 이슈만 제공하고, 비공개 메일·폼이 없다고 명시합니다. About은 운영자 GitHub 계정과 편집 명의를 설명하므로 운영자가 전혀 없는 상태는 아닙니다. 다만 일반 독자와 비공개 개인정보 문의를 다루기에는 불편합니다.

운영자가 실제로 수신할 이메일을 `contactEmail`에 설정하고 수신을 확인하는 방법을 권합니다. 실명·주소를 임의로 만들거나 공개할 필요는 없습니다. 비공개 이메일 부재를 AdSense 자동 탈락 규정으로 단정하지 않습니다.

### 3. 문구 정합성: 현재 소유권 확인과 향후 광고 구분

Privacy의 Future advertising에 'AdSense verification and advertising support ... disabled at launch'라는 기존 문구가 남아 있습니다. 지금은 메타태그/ads.txt 소유권 코드가 활성이고 광고 요청만 꺼져 있으므로 구분해서 갱신하는 것이 정확합니다. 메타태그 자체가 광고 쿠키를 설정한다는 뜻은 아닙니다.

실제 광고를 켜기 전에는 Google 광고로 발생하는 데이터 처리·제3자 쿠키 안내와 적용 지역의 동의/CMP 절차를 완성해야 합니다. **현재 무광고 단계에서 CMP 미설정만으로 심사 불가라고 판정하지 않습니다.** 메타태그로 사이트를 연결하고 검토를 요청할 수 있다는 공식 절차도 확인했습니다.

### 4. 계정에서 확인해야 하는 항목

AdSense Sites에서 guidehollow.com의 실제 상태, Verify 결과, Request review 여부, 필수 계정 설정 및 Policy center 알림을 확인해야 합니다. 공개 Publisher ID와 HTML만으로는 이를 확인할 수 없습니다. 계정 설정이 미완료이면 검토 요청 후에도 심사가 시작되지 않을 수 있다는 공식 안내가 있습니다.

Search Console 색인/방문자/트래픽 출처도 이번에 접근하지 않았습니다. 이를 0으로 해석하지 않습니다. 검색 색인과 AdSense 승인은 별개이며, Search Console 토큰 부재만으로 탈락 판정을 내리지 않습니다.

## 근거와 과장 방지

- [Google 사이트 준비 안내](https://support.google.com/adsense/answer/7299563?hl=en): 독창적 콘텐츠와 사용 경험.
- [승인되지 않은 계정의 콘텐츠 관련 사유](https://support.google.com/adsense/answer/81904?hl=en): 독창적이고 풍부한 콘텐츠, 탐색과 사이트 완성도.
- [Publisher Policies](https://support.google.com/adsense/answer/10502938?hl=en): 낮은 가치 화면의 광고 및 개인정보 고지. 작은 태그 자료실은 noindex만으로 광고 허용이 보장되지 않으며, 현재는 전체 광고 비활성.
- [사이트 연결과 검토 요청](https://support.google.com/adsense/answer/7584263?hl=en): 메타태그 방식, Verify와 Request review의 구분.
- [사이트 승인 상태](https://support.google.com/adsense/answer/12170222?hl=en): 필수 계정 작업 미완료 시 검토 지연 가능.
- [CMP 요구 사항](https://support.google.com/adsense/answer/13554020?hl=en): 해당 지역에서 광고 게재 시 적용되는 요구 사항.

공식 안내에서 '14편이므로 불합격', '30편이면 합격', '글당 1,500단어 필수', '모든 글에 스크린샷 필수' 같은 정량 보장은 확인하지 않았습니다. AI 보조 작성 표시 자체로 자동 탈락 판정을 내리지 않습니다. 화면과 코드가 정상이라는 것 역시 콘텐츠 심사 통과 증명은 아닙니다.

## 이번 작업의 범위

운영 코드·디자인·콘텐츠·설정은 수정하거나 재배포하지 않았습니다. 이번 문서는 로컬 검수 보고서이며 GitHub 커밋/배포 보고서가 아닙니다. 세부 HTTP 검사 증거는 함께 저장한 `adsense-review-evidence-2026-10-23.json`을 참고합니다. 이전 사전 보완 보고서는 당시 상태를 기록한 역사 자료이므로 실제 ID가 비어 있었다는 과거 설명을 현재 상태로 읽지 않아야 합니다.

실제 Google 계정 심사 상태·결제/신원 설정·CMP 지역별 동작·Lighthouse/실사용 CWV·장기 가동률·외부 출처 전체 재검증·표절 전수 비교는 수행하지 않았습니다. 공개 증거만으로 정확한 승인 확률을 계산할 수 없습니다.
