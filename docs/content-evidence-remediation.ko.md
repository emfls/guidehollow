## 실제 수행 증거

- **SUMIFS:** LibreOfficeDev Calc 26.8.0.0.alpha0에서 5개 입력 블록의 수식을 재계산해 150/150/200/120/0 확인. 임시 프로필의 OOXMLRecalcMode=0 사용. 저장 캐시만 읽지 않는지 별도 복사본에서 120→121 입력 변경과 150→151 재계산으로 확인. 원본 수식이 든 XLSX와 JSON 결과 배포. Microsoft Excel 실행 또는 모든 로캘 지원을 주장하지 않음. XLSX 문서 언어 메타데이터 ko-KR, 수식은 XLSX 표준 영어 표기.
- **템플릿:** signed-in ChatGPT web, 표시 모드 High에서 일반/담당자·기한 누락/폐기안 상충의 세 사례를 한 요청으로 실행. 실제 출력의 작업 행·담당자·기한을 입력과 대조. 세 사례 기준 충족, 반복성·모델 비교·빈 노트 분기는 미측정. 원래 요청과 관찰 응답 TXT 배포.
- **요약:** A/B/C 가상 원문과 의도적으로 잘못 쓴 편집 초안을 실제 ChatGPT에 제출. 32명·공휴일 제외·7일 사전 요청과 서면 확정·보증금과 미정 대관료 구분을 관찰 응답 및 원문과 대조. 잘못된 초안을 실제 모델 실패라고 꾸미지 않음. 원문/요청/응답 TXT 배포. 짧은 텍스트 교정이며 긴 파일 처리 성능 시험이 아님.
- **검색:** 실제 ChatGPT 웹 검색이 반환한 OpenAI Library 문서의 원문을 별도로 열고 saved-file 삭제 절을 대조. 대화 삭제와 별도 Library 파일 삭제의 차이를 확인한 소규모 evidence JSON 배포. 계정 파일은 열거나 삭제하지 않음.

공개 자료는 모두 비민감 가상 데이터이며, 사용자 채팅 URL·사이드바·계정 파일·AdSense 계정 내 다른 사이트/수익 정보는 배포하지 않습니다. 사용한 ChatGPT의 내부 모델 버전은 별도 확정하지 않았습니다.

## 계정의 남은 외부 처리

GuideHollow의 사이트 상태는 **준비 중/광고 게재 가능 여부 검토 중**, 소유권 확인과 리뷰 요청은 완료 표시입니다. 리뷰를 중복 요청하거나 사이트를 삭제하지 않았습니다. 정책 센터의 '현재 정책 위반 문제 없음'은 아직 승인되지 않은 이 사이트의 품질 합격 증거가 아닙니다.

계정의 ads.txt 상태는 아직 **찾을 수 없음**이며, 사이트의 실제 `/ads.txt`는 올바른 ID와 정상 응답입니다. 상세 UI에서는 현재 검토 상태에 대한 업데이트 재확인 버튼이 제공되지 않았습니다. 공식 문서는 상태 반영에 며칠이 걸릴 수 있고 광고 요청이 적으면 더 오래 걸릴 수 있다고 설명합니다. 이 상태를 승인됨으로 바꿔 보고하지 않습니다.

CMP·개인정보 고지의 광고용 데이터 처리 설정은 실제 광고를 켜기 전에 별도로 완성해야 합니다. 이번 작업에서는 광고·계정 결제·신원·동의 메시지를 활성화하거나 임의 수정하지 않았습니다. 사용자에게 새로운 유료 API/구독 또는 비밀 키를 요구하지 않았습니다.
